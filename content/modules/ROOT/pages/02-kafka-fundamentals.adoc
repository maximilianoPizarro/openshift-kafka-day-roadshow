= Kafka Fundamentals

== Objectives

* Understand Kafka architecture (brokers, topics, partitions)
* Explore the Kafka cluster using the Streams Console
* Produce and consume messages using the CLI

== Kafka Architecture on OpenShift

The workshop uses **AMQ Streams** (Red Hat's Kafka distribution based on Strimzi) running in **KRaft mode** (no ZooKeeper).

=== Cluster Components

[source,bash,role="execute"]
----
oc get kafka -n kafka-cdc
----

[source,bash,role="execute"]
----
oc get kafkanodepool -n kafka-cdc

[source,yaml]
----
apiVersion: kafka.strimzi.io/v1beta2
kind: KafkaNodePool
metadata:
  name: broker
  namespace: kafka-cdc
  labels:
    strimzi.io/cluster: cdc-cluster
spec:
  replicas: 3
  roles:
    - controller
    - broker
  storage:
    type: jbod
    volumes:
      - id: 0
        kraftMetadata: shared
        type: persistent-claim
        size: 10Gi
----

=== Explore Topics

List all Kafka topics:

[source,bash,role="execute"]
----
oc get kafkatopic -n kafka-cdc
----

You should see these CDC topics:

* `cdc.public.customers` -- Customer table changes
* `cdc.public.orders` -- Order table changes
* `dlq.cdc-errors` -- Dead letter queue for failed events

.Expected topic (offline reference)
[source,yaml]
----
apiVersion: kafka.strimzi.io/v1beta2
kind: KafkaTopic
metadata:
  name: cdc.public.orders
  namespace: kafka-cdc
  labels:
    strimzi.io/cluster: cdc-cluster
spec:
  partitions: 3
  replicas: 3
----

== CLI: Produce Messages

You can produce messages directly from the command line. Start a console producer:

[source,bash,role="execute"]
----
oc run kafka-producer -ti --rm \
  --image=registry.redhat.io/amq-streams/kafka-38-rhel9:latest \
  --restart=Never \
  -n kafka-cdc \
  -- bin/kafka-console-producer.sh \
    --broker-list cdc-cluster-kafka-bootstrap:9092 \
    --topic test-workshop
----

Type a few messages and press Enter after each:

[source,text]
----
Hello from the Kafka workshop!
Event-driven architecture rocks
{"user": "user1", "action": "test"}
----

Press `Ctrl+C` to exit.

== CLI: Consume Messages

In a new terminal, start a consumer to read those messages:

[source,bash,role="execute"]
----
oc run kafka-consumer -ti --rm \
  --image=registry.redhat.io/amq-streams/kafka-38-rhel9:latest \
  --restart=Never \
  -n kafka-cdc \
  -- bin/kafka-console-consumer.sh \
    --bootstrap-server cdc-cluster-kafka-bootstrap:9092 \
    --topic test-workshop \
    --from-beginning
----

You should see all the messages you produced.

== Explore the Kafka Bridge REST API

The Kafka Bridge exposes a REST API for producing and consuming messages via HTTP:

[source,bash,role="execute"]
----
curl -s {bridge_url}/topics | python3 -m json.tool
----

Produce a message via REST:

[source,bash,role="execute"]
----
curl -X POST {bridge_url}/topics/test-workshop \
  -H "Content-Type: application/vnd.kafka.json.v2+json" \
  -d '{"records": [{"value": {"message": "Hello from REST API!", "user": "user1"}}]}'
----
