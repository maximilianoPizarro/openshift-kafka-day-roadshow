= Lab Setup & Overview

****
*Guiding question:* Can you reach the cluster and your own project?
****

== Workshop Architecture

image::workshop-architecture.jpg[OpenShift Kafka Day Roadshow Architecture,width=100%]

You are here: OpenShift, the Terminal, and your personal project. The rest of the pipeline stays dim until later modules.

== Objectives

* Log in to the OpenShift cluster with your assigned user
* Verify CLI access
* Confirm the shared `kafka-cdc` namespace is visible
* Confirm admin access to your personal namespace

== Step 1: Log in to the OpenShift Console

Open the *OCP Console* tab (or this URL in a new window):

link:https://console-openshift-console.{cluster_domain}[OpenShift Console,window=_blank]

Log in with your assigned credentials:

* **Username:** `userN` (replace `N` with the number your instructor assigned)
* **Password:** `{user_password}`

== Step 2: CLI Login

Use the *Terminal* tab in your workshop interface and log in with the `oc` CLI. Replace `user1` with your assigned user:

[source,bash,role="execute",subs="+attributes"]
----
oc login -u user1 -p '{user_password}' https://api.{cluster_base}:6443
----

Verify your identity:

[source,bash,role="execute"]
----
oc whoami
----

You should see `userN`, matching the account you used above.

== Step 3: Explore the Workshop Namespace

The shared workshop infrastructure lives in the `kafka-cdc` namespace. Verify you can view it:

[source,bash,role="execute"]
----
oc get pods -n kafka-cdc
----

You should see pods running for:

* `cdc-cluster` -- Kafka brokers (3 pods)
* `cdc-connect` -- Kafka Connect workers (2 pods)
* `cdc-postgresql` -- PostgreSQL database
* `cdc-data-simulator` -- Transaction simulator
* `cdc-email-transformer` -- Event consumer
* `mailpit` -- Email inbox viewer
* `kafka-console` -- Kafka Console UI

.Expected Kafka cluster (reference, not a step)
[source,yaml]
----
apiVersion: kafka.strimzi.io/v1beta2
kind: Kafka
metadata:
  name: cdc-cluster
  namespace: kafka-cdc
  annotations:
    strimzi.io/node-pools: enabled
    strimzi.io/kraft: enabled
spec:
  kafka:
    listeners:
      - name: plain
        port: 9092
        type: internal
        tls: false
----

== Step 5: Verify Your Personal Namespace

You have admin access to your own namespace. Client pods for produce and consume run here so they do not collide with other participants:

[source,bash,role="execute"]
----
oc project $(oc whoami)-workshop
oc get all
----
