= OpenShift Kafka Day Roadshow

== Workshop Overview

== What You Will Learn

* **Event-Driven Architecture** -- Understand how Kafka enables asynchronous, decoupled microservice communication.
* **Event Generation** -- See a real application producing events from database changes using Debezium.
* **Event Consumption** -- Build and explore event processing pipelines that react to CDC events.
* **Change Data Capture (CDC)** -- Use Debezium to capture PostgreSQL WAL changes and stream them to Kafka topics.
* **Schema and integration** -- Validate those events with Apicurio Registry and a Camel route.
* **Monitoring & Traceability** -- Explore Grafana dashboards, Kafka metrics, and distributed tracing with OpenTelemetry.

== Architecture

The workshop deploys the following CDC pipeline on your OpenShift cluster:

image::cdc-architecture.jpg[OpenShift Kafka Day Roadshow CDC Pipeline,width=100%]

[cols="1,2"]
|===
|Component |Description

|AMQ Streams (Strimzi)
|Apache Kafka 3.x cluster with KRaft (no ZooKeeper)

|PostgreSQL 16
|Source database with WAL logical replication enabled

|Debezium
|CDC connector capturing INSERT/UPDATE/DELETE from PostgreSQL

|Kafka Connect
|Connector runtime hosting Debezium source and HTTP Sink connectors

|CDC Data Simulator
|Python app generating realistic banking transactions

|Email Transformer + Mailpit
|Event consumer sending formatted CDC notifications

|Kafka Streams Console
|Web UI for browsing topics, messages, and consumer groups

|Grafana
|Dashboards for Kafka broker metrics, consumer lag, and Debezium stats

|OpenTelemetry
|Distributed tracing collector

|Apicurio Registry
|JSON Schema registry for customer and order rows, stored in Kafka

|Camel
|Route that validates CDC rows and lab messages against Apicurio
|===
