= OpenShift Kafka Day Roadshow

== Workshop Overview

NeuralBank's core banking application writes customers and orders to PostgreSQL. The bank wants an email when a row changes, plus a way to reject a bad event, without editing that application. Today you will watch the database emit a change, follow it through Kafka, see the email, check the event against a schema, and read the pipeline's health.

This is a hands-on workshop on Event-Driven Architecture with Apache Kafka, Debezium Change Data Capture (CDC), and observability on Red Hat OpenShift.

*Duration:* 2 hours +
*Format:* Hands-on workshop

== What You Will Learn

* **Lab Setup & Overview** -- Reach the cluster, the shared `kafka-cdc` namespace, and your personal project.
* **Kafka Fundamentals** -- Brokers, topics, and partitions; produce and consume with the CLI and the Kafka Bridge.
* **Event Producer** -- Watch a banking simulator write to PostgreSQL and see the change appear in Kafka.
* **Event Consumer** -- Follow the HTTP Sink through the email transformer into Mailpit.
* **Debezium CDC** -- See how PostgreSQL WAL changes become Kafka records.
* **Camel and Apicurio Registry** -- Validate rows against a JSON Schema and reject bad events without stopping the pipeline.
* **Monitoring** -- Read Grafana dashboards, consumer lag, and Debezium metrics.
* **Wrap-up** -- Recap the architecture and what to harden before production.

== Architecture

The workshop deploys the following CDC pipeline on your OpenShift cluster. Each module lights up a slice of this diagram; the landing page shows the full picture so you know where you are going.

image::cdc-architecture.jpg[OpenShift Kafka Day Roadshow CDC Pipeline,width=100%]

[cols="1,2"]
|===
|Component |Description

|AMQ Streams (Strimzi)
|Red Hat AMQ Streams, Apache Kafka 4.2, KRaft (no ZooKeeper)

|PostgreSQL 16
|Source database with WAL logical replication enabled

|Debezium
|CDC connector capturing INSERT/UPDATE/DELETE from PostgreSQL

|Kafka Connect
|Connector runtime hosting Debezium source and HTTP Sink connectors

|CDC Data Simulator
|Python app generating realistic banking transactions

|Email Transformer + Mailpit
|Event consumer sending formatted CDC notifications

|Kafka Console
|Web UI for browsing topics, messages, and consumer groups (not the Kafka Streams API)

|Grafana
|Dashboards for Kafka broker metrics, consumer lag, and Debezium stats

|Apicurio Registry
|JSON Schema registry for customer and order rows, stored in Kafka

|Camel
|Route that validates CDC rows and lab messages against Apicurio
|===
